# nfc4all — قوالب بطاقات زيارة رقمية (6 تصاميم)

كل قالب = **ملف `index.html` واحد** + مجلد `img/`. بلا قاعدة بيانات، بلا اشتراك شهري، وكيخدم مباشرة على GitHub Pages.
جميع التصاميم كتدعم **العربية (RTL) + الفرنسية + الإنجليزية** مع أزرار تبديل اللغة، وفيها **فيسبوك + إنستغرام + تيك توك**، **حفط جهة الاتصال (vCard)**، **واتساب**، **اتجاهات Google Maps**، و**زر تقييم Google**.

## 2) طريقة العمل (5 خطوات)

1. نسخ مجلد القالب وسميه باسم الزبون: `clients/salon-rachid` → `clients/hammam-nour`.
2. حل `index.html` بأي محرر نصوص (VS Code / Notepad) وبدّل **غير داخل منطقة `EDIT ZONE`**.
3. بدّل الصور ف `img/` بنفس الأسماء (الصور الموجودة مجرد أمثلة — خد صور الزبون الحقيقية).
4. دفع (push) المجلد لـ GitHub وفعّل **Settings → Pages → Deploy from branch → main / root**.
5. الرابط اللي كتدير ف شريحة NFC هو **رابط الوسيط**:
   `https://<username>.github.io/<repo>/c/0001/`

**لاش مهم:** الشريحة كتكتب مرة وحدة برقم البطاقة. ملّي الزبون يبغي يبدل التصميم أو الرقم أو الأثمنة، كتبدّل **سطر واحد** ف `c/000X/index.html` بلا ما تقرّب للشريحة. (مفيدة بزاف مع اعتراض «ملّي كتبدّل الرقم ولا الأسعار؟».)

بدّل هاد السطر ف 3 مواقع داخل `c/000X/index.html` (meta refresh + الرابط + `location.replace`).

## 4) الحقول المشتركة ف جميع التصاميم

داخل `EDIT ZONE`:

- `defaultLang` · `autoDetectLang`
- `name` · `role` · `city` · `bio` — كل واحد `{ ar, fr, en }`
- `phone` · `whatsapp` · `email` · `website`
- `maps` · `address`
- `facebook` · `instagram` · `tiktok`
- `review` — رابط تقييم Google
- `services` أو `menu` · `gallery` · `hours`
- `vcard` — معلومات ملف جهة الاتصال (`fileName` = اسم الملف اللي كيتحمل)
- `brand` — توقيعك أنت (nfc4all) ف أسفل البطاقة

**قاعدة مهمة:** أي حقل خلّيتو خاوي `""` → كيختفي الزر/القسم ديالو من البطاقة أوتوماتيكياً. ما خاصكش تحيد كود.

### حقول خاصة بتصاميم معينة

| التصميم | حقول زائدة |
|---------|-------------|
| 1 Classic | `logoShape` (`"square"` أو `"circle"`) · `cover` |
| 2 Noir | `hero` · `accentText` |
| 3 Vivid | `cover` · `accentSoft` |
| 4 Aurora | `accent1` · `accent2` · `background` · `avatar` · `extraLinks` · `hoursNote` |
| 5 Bento | `accent` · `accent2` · `logo` · `badge` · `stats[{value,label}]` · `hoursNote` · `gallery` (4 صور) |
| 6 Carte | `accent` · `accent2` · `gold` · `logo` · `menu[{img,name,desc,price}]` · `gallery[{src,caption}]` · `hoursNote` |

## 5) مقاسات الصور

| النوع | المقاس | الجودة |
|-------|---------|---------|
| لوغو / أفاتار | 400×400 | 90 |
| صورة غلاف (cover / hero) | 1200×800 | 82 |
| صور مربعة (معرض / منيو) | 900×900 | 82 |
| صور عريضة 16:9 (تصميم 6) | 1200×675 | 82 |

أمر التصغير (ImageMagick):

```bash
magick photo.jpg -resize 900x900^ -gravity center -extent 900x900 -quality 82 -strip img/g1.jpg
```

خلّي وزن كل صورة تحت **200 كيلوبايت** باش البطاقة تتفتح بزربة على 4G.

## 6) قائمة فحص قبل التسليم

- [ ] الاسم والمهنة مكتوبين مزيان ف 3 لغات (أو على الأقل العربية + الفرنسية)
- [ ] الرقم كيخدم: ضغط على زر الاتصال من الهاتف
- [ ] واتساب كيفتح المحادثة مع الرقم الصحيح
- [ ] حفط جهة الاتصال كيحمل ملف `.vcf` وكيتسجل ف الهاتف
- [ ] فيسبوك / إنستغرام / تيك توك كيفتحو الصفحة الصحيحة
- [ ] الاتجاهات كتفتح Google Maps على المحل بالضبط
- [ ] رابط التقييم كيفتح نافذة النجوم (ماشي خاوي `XXXXXXXX`)
- [ ] الأثمنة وأوقات العمل مصدقة مع الزبون
- [ ] جميع الصور ديال الزبون (ماشي الأمثلة)
- [ ] جرّب البطاقة على أندرويد + آيفون
- [ ] رابط `c/000X/` كيوجّه مزيان، والشريحة مقفولة (locked) من بعد الكتابة

## 7) تجريب محلي

- حل `index.html` (اللي ف الجزر) — فيه أزرار للستة تصاميم باش توريهم للزبون.
- لفحص لغة معينة: `index.html?lang=fr` أو `?lang=en` أو `?lang=ar`.
- تصميم 6: `index.html?flip=1` كيفتح البطاقة على الوجه الخلفي مباشرة.
- على `file://` ديما حل الرابط الكامل `…/index.html` (المجلد الفارغ كيبقى أبيض).
